# Optimal Health OS — Live Demo

**Try it: https://optimal-research-team.github.io/optimal-health-os-demo/**

Two panes: the app itself (static mirror, fully navigable), and the SMS
coach as a phone you can actually text — including a structured post-op
follow-up flow. Three switchable brains for the phone (✨): the product's
grounded deterministic engine, an in-browser LLM via WebGPU, or your own
Anthropic API key (stored only in your browser).

**Everything here is fabricated sample data for a fictional person. It is
a product demo, not medical advice.** The real product is local-first and
private — this repo contains only the generated demo site.
