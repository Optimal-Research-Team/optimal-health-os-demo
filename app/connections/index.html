Apple Health

WAITING FOR FIRST PUSH
SLEEP · RESTING HR · HRV

Apple keeps Health data on-device, so sync runs through the Health Auto Export iOS app pushing JSON to this endpoint on a schedule:

  1. Set APPLE_HEALTH_SECRET in your env.
  2. In Health Auto Export, create a REST API automation → URL http://localhost:3000/api/ingest/apple-health
  3. Add header Authorization: Bearer <your secret>, format JSON, metrics: sleep, resting heart rate, HRV.

Same-day re-pushes update in place, so aggressive schedules are safe.
